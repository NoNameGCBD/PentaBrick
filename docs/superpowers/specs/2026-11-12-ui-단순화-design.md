# UI 단순화 설계

날짜: 2026-11-12 · 상태: 검토 대기

## 1. 목적

지금 UI는 글자 상단 바, 소제목이 달린 오른쪽 패널, 단축키·점수 규칙이 적힌 글자 버튼 때문에 웹 시뮬레이터처럼 보인다. 일반적인 퍼즐 게임처럼 **화면마다 할 일 하나를 크게 두고, 나머지는 아이콘으로 내린다.**

성공 기준
- 게임 화면에 글자 소제목과 글자 위주의 패널이 없다. 3D 화면이 화면 대부분을 차지한다.
- 가로(PC)와 세로(폰) 화면 모두에서 플레이할 수 있다.
- 기존 기능은 하나도 잃지 않는다(아래 4장의 "옮김" 표 참고).
- EditMode 테스트는 그대로 통과하고, PlayMode 테스트는 새 UI 기준으로 다시 써서 통과한다.

범위 밖: 색 테마·글꼴 교체(한글 글꼴은 9단계), 효과음, 터치 제스처(8단계 별도), 새 게임 기능(별점·레벨 진행 등). `GameState`와 Core는 바꾸지 않는다.

## 2. 화면 흐름

지금과 같다: 인트로 → 메인 → 모드 선택 → 게임. 공유 주소로 들어오면 바로 게임.

## 3. 화면별 설계

### 3.1 메인
- 가운데: 제목 `PentaBrick`, 버튼 **플레이**(초록), **튜토리얼**. 두 버튼은 같은 크기이고 색으로만 구분한다.
- 오른쪽 위: 설정 아이콘(⚙).
- 아래: 점수가 0이 아니면 `★ 점수`를 작게.
- 없앰: 부제 문장, 규칙 요약 두 줄.
- Esc: 종료 확인 창(이미 구현됨, 그대로).

### 3.2 모드 선택
- 가운데: 타일 4개를 한 줄로(세로 화면에서는 2×2). `연습 · 샘플 6` / `쉬움 · 3×3` / `보통 · 4×4` / `어려움 · 5×5`.
- 왼쪽 위: 뒤로 아이콘(←) → 메인.
- 오른쪽 위: 문제 코드 아이콘(#) → 작은 창(입력 칸, 열기, 오류 문장).
- Esc: 열린 코드 창을 닫고, 없으면 메인으로.

### 3.3 게임 (시안 A)

```
가로                                     세로
┌──────────────────────────────────┐    ┌──────────┐
│❚❚       [■][■][■][■][■]  ★3 01:24│    │❚❚   01:24│
│                                  │    │[■][■][■][■][■]│
│            (3D 화면)              │    │  (3D)    │
│                                  │    │          │
│ ✚ 🖌 ✕ │ ●2 ●1 ●0 ●3 │ ↶ ↷ 📷 │ 불가능 [제출] │    │●●●● ✚🖌✕ │
└──────────────────────────────────┘    │↶↷📷 불가능 제출│
                                        └──────────┘
```

**위쪽 HUD**
- 왼쪽: 일시정지 아이콘(❚❚). Esc와 같다.
- 가운데: 평면도 카드 5장(위·앞·뒤·왼쪽·오른쪽). 카드에는 목표 평면도만 그린다. "내 모형 평면도 표시"(연습 모드 전용, 켜면 점수 미반영)가 켜져 있을 때만, 내 모형과 일치하는 카드의 테두리가 초록색이 된다(일치 여부 자체가 힌트이므로).
- 오른쪽: `★ 점수`, 경과 시간. 문제 이름(샘플 번호, 난이도·코드)은 일시정지 창 제목으로 옮긴다.

**평면도 카드 누르기**
- 카드를 누르면 카메라가 그 방향으로 돌아가고, 그 카드가 줄 바로 아래에 크게 펼쳐진다.
- 같은 카드를 다시 누르거나 카메라 아이콘(📷)을 누르면 기본 시점으로 돌아가고, 펼친 카드가 닫힌다.
- 연습 모드에서 "내 모형 평면도 표시"가 켜져 있으면, 펼친 카드에 목표와 내 모형을 나란히 그린다.

**아래 트레이** (한 줄. 세로 화면에서는 두 줄로 접힘)
- 도구: 놓기(✚) · 칠하기(🖌) · 지우기(✕). 선택된 도구는 강조 표시.
- 색 칩: 문제에 쓰이는 색만 동그란 칩으로. 오른쪽 아래에 남은 개수. 선택된 색은 흰 테두리, 남은 개수가 0이면 흐리게.
- 편집: 실행 취소(↶) · 다시 실행(↷) · 기본 시점(📷). 초기화는 일시정지 창으로 옮긴다.
- 판정: **불가능**(보조 버튼), **제출**(초록, 가장 큼). 제출할 수 없으면 흐리게 둔다. 안내 문장은 없앤다.

**글자 줄이기**
- 버튼에서 단축키 `(Q)`·`(Esc)`, 점수 규칙 `(±1)`·`(±2)`를 뺀다. 단축키는 그대로 동작하고, 아이콘 버튼에는 툴팁(`tooltip`)으로 이름과 단축키를 단다.
- 시점 버튼 줄(기본·위·앞·뒤·왼쪽·오른쪽)을 없앤다. 평면도 카드와 📷 아이콘이 대신한다.

### 3.4 결과 팝업
- 제출하거나 불가능을 선언하면, 화면 가운데에 팝업이 뜬다(3D 화면은 그대로 보인다).
- 내용: 큰 제목(`정답!` / `오답` / `맞습니다, 불가능한 문제` / `틀렸습니다, 만들 수 있는 문제`), 큰 점수(`+2`), 작은 부가 설명(시간 보너스, 점수 미반영 이유, 불가능 이유 문장).
- 버튼: **다음 문제**(초록, 큰 버튼). 아이콘: 정답 모형 보기(👁, 정답이 있을 때만) · 코드 복사(🔗, 생성 문제만) · 메인(⌂).
- 오답이면 "일치하지 않는 평면도" 문장 대신, 위쪽 평면도 줄에서 틀린 카드에 빨간 테두리를 친다. 색별 블록 수가 틀렸으면 그 색 칩에 빨간 테두리를 친다.
- 정답 모형 보기를 누르면 팝업이 작게 접혀 아래로 내려간다(다음 문제 버튼만 남음). 그래야 3D 화면에서 정답 모형을 볼 수 있다.

### 3.5 일시정지 (Esc / ❚❚)
- 제목: 문제 이름(예: `샘플 2 / 6`, `보통 · 1p0wp`).
- 큰 버튼: **계속하기**(초록), **새 문제**(샘플이면 "다음 샘플").
- 작은 아이콘 줄: 다시 시작(초기화) · 설정(⚙) · 코드 복사(🔗, 생성 문제만) · 튜토리얼(?) · 메인(⌂).
- 없앰: "난이도 변경"(메인을 거쳐 감).
- 풀던 문제를 버리는 행동(새 문제·튜토리얼·메인)은 지금처럼 확인 창을 거친다.

### 3.6 설정
- 메인의 ⚙와 일시정지의 ⚙가 같은 창을 연다. 내용은 지금과 같다(소리 크기, 내 모형 평면도 표시, 점수 초기화).
- "내 모형 평면도 표시"는 게임 밖(메인)에서 열었을 때도 보이되, 연습 모드 전용이라는 설명은 유지한다.

### 3.7 그대로 두는 것
인트로, 종료 확인 창, 풀던 문제 확인 창, 첫 접속 튜토리얼 안내, 화면 전환·창 열기/닫기 애니메이션.

## 4. 옮김 표 (기능을 잃지 않는지 확인)

| 지금 위치 | 기능 | 새 위치 |
|---|---|---|
| 상단 바 | 문제 이름 | 일시정지 창 제목 |
| 상단 바 | 점수, 시간 | 게임 HUD 오른쪽 위 |
| 상단 바 | 메뉴 (Esc) | HUD 왼쪽 위 ❚❚ |
| 평면도 띠 | 목표/내 모형 평면도, 일치 표시 | 평면도 카드(초록 테두리), 펼친 카드 |
| 시점 버튼 줄 | 기본/5방향 시점 | 📷 아이콘 / 평면도 카드 누르기 |
| 오른쪽 패널 | 색 선택, 남은 개수 | 트레이 색 칩 |
| 오른쪽 패널 | 놓기/칠하기/지우기 | 트레이 도구 아이콘 |
| 오른쪽 패널 | 실행 취소/다시 실행 | 트레이 ↶ ↷ |
| 오른쪽 패널 | 초기화 | 일시정지 창 "다시 시작" |
| 오른쪽 패널 | 정답 제출, 불가능 | 트레이 제출, 불가능 |
| 오른쪽 패널 | 결과 상자, 정답 보기 | 결과 팝업 |
| Esc 메뉴 | 다음 샘플/새 문제, 코드 복사, 튜토리얼, 설정, 메인 | 일시정지 창 |
| Esc 메뉴 | 난이도 변경 | 없앰(메인 → 플레이) |
| 모드 선택 | 문제 코드 입력 | # 아이콘 → 작은 창 |
| 메인 | 규칙 요약 | 없앰(튜토리얼에서 설명) |

## 5. 구현 구조

**파일 나누기.** `GameUI`는 `partial class`로 나눈다. 클래스는 하나라서 `BlockEditor`와 테스트가 쓰는 공개 API(`Show`, `Play`, `OnEscape`, `IsMenuOpen`, `IsConfirming`, `IsQuitOpen`, `IsTransitioning`, `IsPointerOverUI` 등)는 유지한다.

| 파일 | 내용 |
|---|---|
| `View/GameUI.cs` | 필드, 시작, `Update`, 화면 이동, Esc, 전환 애니메이션, 공통 헬퍼 |
| `View/GameUI.Game.cs` | 게임 HUD, 평면도 카드, 트레이, 결과 팝업 |
| `View/GameUI.Menus.cs` | 메인, 모드 선택, 코드 창, 일시정지, 설정, 확인 창, 튜토리얼 안내 |
| `View/Icons.cs` | 아이콘 그리기 |

**아이콘.** WebGL에는 OS 글꼴이 없고 지금 글꼴에 기호가 없을 수 있으므로, 글꼴 대신 UI Toolkit `generateVisualContent` + `Painter2D`로 선과 도형을 그린다. 이미지 파일을 쓰지 않는다. 필요한 아이콘: 일시정지, 설정, 뒤로, 문제 코드(#), 놓기, 칠하기, 지우기, 실행 취소, 다시 실행, 카메라(기본 시점), 다시 시작, 링크, 물음표, 집, 눈. 모양은 단순한 선 아이콘이면 충분하다.

**가로/세로.** 루트 요소의 `GeometryChangedEvent`에서 높이 > 너비면 세로 배치로 보고, 배치가 바뀌었을 때만 다시 그린다.

**펼친 평면도 카드.** 어느 카드를 펼쳤는지는 UI 상태(`expandedView`)로 두고, `BlockEditor.SetView`와 함께 바꾼다. 화면을 나가거나 새 문제를 시작하면 닫는다.

**결과 팝업.** `state.Phase == Phase.Result`일 때 그린다. 정답 보기로 접혔는지는 UI 상태로 둔다. 기존 창 애니메이션(열기·닫기)을 그대로 쓴다. 결과 팝업이 떠 있는 동안 3D 편집은 지금처럼 막힌다(`Phase`가 `Playing`이 아니므로).

**튜토리얼.** 안내 카드는 평면도 줄 아래, 3D 화면 위쪽에 띄운다(트레이를 가리지 않게). `Tutorial.cs`의 문장 중 "아래 시점 버튼", "지우기 도구(E)", "칠하기 도구(W)", "'정답 제출'", "Esc를 누르면 메뉴에서"를 새 UI 이름에 맞게 고친다. 문장만 바뀌므로 `TutorialTests`는 문장을 비교하는 곳이 있으면 함께 고친다.

## 6. 테스트

- EditMode(Core·GameState·Tutorial): 그대로 통과해야 한다.
- PlayMode: 버튼을 글자(`"메뉴 (Esc)"`, `"게임 시작"`, `"설정"` 등)로 찾던 곳을 요소 `name`으로 찾게 바꾼다. 아이콘 버튼과 주요 버튼에 `name`을 붙인다(예: `pause`, `play`, `submit`, `impossible`, `tool-place`, `color-1`, `view-front`).
- 새로 확인할 것:
  - 평면도 카드를 누르면 카메라 시점이 바뀌고 카드가 펼쳐진다. 다시 누르면 닫힌다.
  - 결과 팝업이 뜨고, 오답이면 틀린 평면도 카드에 표시가 붙는다. "다음 문제"로 다음 문제가 시작된다.
  - 세로 화면(예: 400×800)에서 트레이가 두 줄로 접히고, 모든 버튼이 화면 안에 들어온다.
  - 일시정지 창에서 다시 시작·새 문제·메인이 확인 창을 거친다.
- 각 화면을 가로·세로로 캡처해 `Logs/`에 저장한다(지금 테스트의 `Save`처럼). 사람이 눈으로 확인한다.

## 7. 위험

| 위험 | 대응 |
|---|---|
| PlayMode 테스트를 대부분 다시 써야 함 | 이름(`name`)으로 찾는 헬퍼를 먼저 만들고, 화면 하나씩 옮긴다 |
| 아이콘을 직접 그려서 보기 어색할 수 있음 | 선 굵기·크기를 상수 하나로 모으고, 캡처를 보며 조정한다 |
| 평면도 카드가 작아져 5×5×3 문제에서 읽기 어려움 | 카드 최소 크기를 두고, 펼친 카드로 크게 볼 수 있다 |
| 세로 화면에서 트레이 버튼이 너무 작음 | 버튼 최소 크기 44px(터치 기준)를 지키고, 넘치면 두 줄로 접는다 |
