# UI 단순화 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 웹 시뮬레이터처럼 보이는 UI를 퍼즐 게임 구조(위 평면도 줄 + 아래 트레이, 결과 팝업, 아이콘 위주 메뉴)로 바꾸고 가로·세로 화면을 모두 지원한다.

**Architecture:** `GameUI`를 `partial class` 네 파일로 나누고, 화면 하나씩 다시 만든다. UI는 지금처럼 `Build()`가 매번 코드로 새로 그린다. 아이콘은 `Painter2D`로 그린다. `GameState`, `BlockEditor`, Core는 바꾸지 않는다(튜토리얼 문장만 예외).

**Tech Stack:** Unity 6000.6.1f1, UI Toolkit(코드로 생성), Input System, NUnit(Unity Test Framework)

**Spec:** [docs/superpowers/specs/2026-11-12-ui-단순화-design.md](../specs/2026-11-12-ui-단순화-design.md)

## Global Constraints

- `GameState`·`BlockEditor`·Core의 공개 API는 바꾸지 않는다. `Tutorial.cs`는 문장만 고친다.
- `GameUI`의 기존 공개 멤버(`Show`, `Play`, `OnEscape`, `EnterMain`, `StartTutorial`, `SkipTutorial`, `CurrentScreen`, `HasProgress`, `InTutorial`, `IsAskingTutorial`, `IsConfirming`, `IsMenuOpen`, `IsQuitOpen`, `IsTransitioning`, `IsPointerOverUI`, `IsTyping`, `ClosingClass`, `TutorialSeenKey`)는 유지한다.
- 버튼에서 단축키 `(Q)`·`(Esc)`, 점수 규칙 `(±1)`·`(±2)` 글자를 뺀다. 아이콘 버튼에는 `tooltip`으로 이름과 단축키를 단다(예: `"놓기 (Q)"`).
- 아이콘은 글꼴 기호나 이미지 파일을 쓰지 않고 `Painter2D`로 그린다.
- 터치 대상 최소 크기 44px.
- 전환·창 열기/닫기 애니메이션(`Modal()`, `screenCover`, `closingOverlay`)은 그대로 쓴다. 새 창도 `Modal()`로 만든다.
- C# 9까지(`record`, `init` 금지).

## Review Focus

명세서가 말하지 않지만 실제로 생길 상황. 각 항목의 테스트를 해당 Task에 넣었다.

1. 게임 도중 창 크기가 바뀌어 가로↔세로가 바뀜(펼친 평면도 카드·결과 팝업이 떠 있는 상태) → 상태를 잃지 않고 새 배치로 다시 그림 (Task 8)
2. 어려움(5×5×3, 6색) 문제를 폭 400px 세로 화면에서 풂 → 색 칩 6개와 모든 트레이 버튼이 화면 안에 들어오고 44px 이상 (Task 8)
3. 결과 팝업이 떠 있을 때 평면도 카드를 누름 → 카메라는 돌아가지만(정답 모형 확인용) 편집은 안 됨 (Task 5)
4. 새로 생긴 창들에서 Esc: 모드 선택의 코드 창, 메인에서 연 설정, 결과 팝업 중 → 열린 창 하나만 닫히거나(코드 창·설정), 결과 중에는 일시정지가 열림 (Task 6, 7)
5. 단축키(Q/W/E, 1~6, Ctrl+Z)로 상태를 바꿈 → 트레이의 강조 표시가 따라 바뀜 (Task 4)

참고: 명세서 3.4의 "색별 블록 수가 틀리면 색 칩에 빨간 테두리"는 구현하지 않는다. 색마다 남은 개수가 있어야 놓을 수 있고 제출은 전체 개수가 같아야 하므로, 제출 시 색별 개수는 항상 맞다.

### Task 2: 아이콘

**Files:**
- Create: `Assets/PentaBrick/View/Icons.cs`
- Modify: `Assets/PentaBrick/View/GameUI.cs` (헬퍼 추가)
- Test: `BlockEditorPlayTests.cs`

**Interfaces:**
- Produces:
  ```csharp
  public enum Icon { Pause, Settings, Back, Code, Place, Paint, Erase, Undo, Redo, Camera, Restart, Link, Help, Home, Eye }
  public static class Icons { public static VisualElement Make(Icon icon, float size, Color color); }
  // GameUI 헬퍼
  private Button IconButton(VisualElement parent, string name, Icon icon, string tooltip, Action onClick, float size = 44f);
  ```
- `Make`는 `size×size` 요소에 `generateVisualContent`로 선(굵기 `size * 0.09f`, 둥근 끝)을 그린다. 아이콘 모양은 구현자가 정한다. 단순한 선 아이콘이면 된다(일시정지=세로 막대 둘, 놓기=+, 지우기=×, 실행 취소=왼쪽으로 굽은 화살표, 다시 실행=그 좌우 반전, 카메라=사각형+원, 설정=톱니 대신 원+짧은 선 6개 허용, 코드=#, 집=오각형, 눈=아몬드+원, 링크=고리 둘, 도움말=?, 다시 시작=원형 화살표, 칠하기=붓 또는 물방울, 뒤로=←).
- `IconButton`은 배경이 둥근 사각형(지름의 25% 반경)인 버튼 안에 아이콘을 넣고, `tooltip`과 `name`을 단다. 비활성 시 투명도 0.35.
