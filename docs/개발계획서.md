# PentaBrick Unity 개발 계획서 (졸업작품)

- 작성일: 2026-11-12
- 기준 문서: [기획명세서.md](기획명세서.md) (웹 프로토타입 v0.3)
- 목표: 웹 프로토타입으로 검증한 규칙을 Unity로 옮기고, 명세서 로드맵 4~6단계(솔버·불가능 문제, 점수 체계, 튜토리얼)까지 완성해 졸업작품으로 제출한다.

## 1. 개발 환경과 기술 선택

| 항목 | 선택 | 이유 |
|---|---|---|
| 엔진 | Unity 6000.6.1f1 | 이미 설치되어 있음 (WebGL / macOS / Windows 빌드 모듈 포함) |
| 언어 | C# | |
| 프로젝트 위치 | `pentabrick/unity/` | 명세서·웹 프로토타입과 같은 저장소에서 관리. 웹 프로토타입은 "정답지"로 남겨 둔다 |
| 렌더 파이프라인 | URP | Unity 6 기본. WebGL에서도 가벼움 |
| UI | UI Toolkit (UXML/USS) | 명세서 5장의 3열 패널 레이아웃이 웹 DOM 구조와 거의 1:1로 대응 |
| 입력 | Input System | 마우스·키보드·터치를 한 코드로 처리 (6단계 모바일 대비) |
| 테스트 | Unity Test Framework (NUnit, EditMode) | 코어 로직은 엔진 없이 테스트 |
| 빌드 대상 | WebGL(시연·공유용) + Windows/macOS 실행 파일(발표용) | |

## 2. 구조 원칙

명세서 7.2의 의존 방향 `ui → game → core`를 어셈블리 정의(asmdef)로 강제한다.

```
unity/Assets/PentaBrick/
  Core/     PentaBrick.Core.asmdef   순수 C# (UnityEngine 참조 금지) — 모형, 평면도, 판정, 문제, 생성기, 솔버
  Game/     PentaBrick.Game.asmdef   순수 C# — 게임 상태, 액션, 실행 취소, 타이머, 점수
  View/     PentaBrick.View.asmdef   MonoBehaviour — 3D 에디터, 카메라, UI Toolkit 패널
  Tests/    PentaBrick.Tests.asmdef  EditMode 테스트
```

- Core는 엔진을 모르므로 테스트가 빠르고, 나중에 서버 판정(명세서 9장)으로 옮길 수 있다.
- 웹 프로토타입과 **같은 seed는 같은 문제**가 나오도록 난수 생성기까지 그대로 옮긴다. 웹판에서 뽑은 값을 테스트에 넣어 대조한다.

## 3. 단계별 계획

각 단계는 "돌아가는 결과물 + 테스트 통과"로 끝난다. 단계마다 상세 계획 문서를 `docs/plans/`에 따로 쓴다.

| 단계 | 내용 | 완료 기준 | 명세서 |
|---|---|---|---|
| **1** | Unity 프로젝트 생성, Core 이식(모형·평면도·판정·샘플 문제·생성기), 테스트 이식 | EditMode 테스트 전부 통과, 웹판과 seed 결과 일치 | 2, 4, 6장 |
| 2 | Game 상태: 문제 시작, 놓기/칠하기/지우기 액션, 실행 취소·다시 실행, 제출·불가능 판정, 타이머, 점수 | 상태 전이 테스트 통과 | 3장, 6.5 |
| 3 | 3D 에디터: 블록 렌더링, 클릭 판정(놓기 미리보기 포함), 궤도 카메라, 시점 버튼, 방향 라벨 | 에디터에서 블록을 쌓고 지울 수 있음 | 5.4 |
| 4 | UI: 상단 바, 평면도 패널, 조작 패널, 결과 상자, 단축키 | 샘플 6문제를 처음부터 끝까지 플레이 가능 | 5.1~5.8 |
| 5 | 문제 모드와 공유: 샘플/쉬움/보통/어려움, 문제 코드 입력·복사, WebGL 주소 `?mode=&seed=` | 웹판과 같은 코드로 같은 문제가 열림. **여기까지가 웹 프로토타입 동등 수준** | 4장 |
| 6 | 솔버(제약 충족 탐색) → 불가능 문제 자동 생성, 해의 개수로 난이도 보정 | 생성 모드에 불가능 문제 등장, 솔버가 샘플의 가능/불가능을 모두 맞힘 | 로드맵 4 |
| 7 | 점수 체계: 시간 가산점, 난이도 가중치, 점수·기록 저장 | 재시작해도 기록 유지 | 로드맵 5 |
| 8 | 튜토리얼, 터치 조작, 효과음·애니메이션 등 다듬기 | 처음 보는 사람이 설명 없이 플레이 | 로드맵 6 |
| 9 | 빌드(WebGL·Windows·macOS), 졸업작품 보고서·시연 영상·발표 자료 | 제출물 완성 | |

백엔드·랭킹(명세서 로드맵 7)은 졸업작품 범위에서 제외한다.

### 진행 상황 (2026-11-12)

| 단계 | 상태 | 비고 |
|---|---|---|
| 1 Core 이식 | 완료 | 웹판과 같은 seed → 같은 문제 확인 |
| 2 게임 상태 | 완료 | |
| 3 3D 에디터 | 완료 | 미리보기는 반투명 대신 작은 블록, 바닥 방향 라벨 없음 |
| 4 UI | 완료 | 화면 폭 980px 이하 세로 배치 없음 |
| 5 문제 모드와 공유 | 완료 | 문제 코드 입력·복사, 주소(`?mode=&seed=`)로 시작. WebGL 빌드에서의 동작과 주소창 갱신은 9단계 빌드 때 확인 |
| 6 솔버·불가능 문제 | 완료 | 생성 문제의 10~20%(문제마다 무작위, 평균 약 15%)가 불가능 문제. 이유는 자동 문장. "해의 개수로 난이도 보정"은 하지 않음 |
| 7 점수 체계 | 완료 | 시간 보너스 +1(쉬움 1분·보통 3분·어려움 6분 안에 정답 제출, 샘플·불가능 선언 제외). 난이도 가중치 없음. "내 모형 평면도 표시"는 연습(샘플) 모드에서만 사용 가능, 켠 문제는 점수 미반영(기본 꺼짐). 점수는 게임을 끄면 초기화(추후 별도 데이터베이스에 저장 예정), 설정에서 초기화 |

| (변경) 화면 구성 | 완료 | 사용자 요청: 메인 화면 → 게임 시작 → 난이도 선택 → 게임. 평면도를 왼쪽 패널에서 상단 띠로 옮김. 명세서 5.1의 3열 배치와 다름 |

| (변경) Esc 메뉴 | 완료 | 새 문제·코드 복사·난이도 변경·설정(소리 크기, 내 모형 평면도 표시)·메인 메뉴·조작법을 Esc 메뉴로 옮기고 게임 화면의 오른쪽 패널은 블록·도구·편집·제출만 남김. 풀던 중 나가면 확인 창 |

| 8 다듬기 — 튜토리얼 | 완료 | 첫 접속 시 튜토리얼 안내(시작/건너뛰기, 한 번 고르면 다시 묻지 않음). 메인 화면과 Esc 메뉴에 튜토리얼 버튼. 2×2 문제 두 개로 10단계(평면도 읽기 → 놓기 → 쌓기 → 시점·고치기 → 완성·제출 → 점수 → 불가능 선언). 점수 미반영 |
| 8 다듬기 — 인트로 | 완료 | 메인 화면 전에 인트로: 여섯 색 블록이 차례로 떨어지고 제목이 나타난 뒤 중하단에 "PRESS ANY BUTTON" 점멸. 아무 키·마우스·터치·게임패드(시작/A)로 메인 진입. 공유 주소로 들어오면 인트로 생략 |
| (변경) 메인 화면 Esc | 완료 | 메인 화면에서 Esc를 누르면 게임 종료 확인 창(취소/종료). 에디터에서는 플레이 모드 종료, WebGL에서는 종료되지 않음 |

| 8 다듬기 — 효과음·터치 | 대기 | |

테스트: EditMode 76개, PlayMode 8개(메인 화면 Esc 테스트는 아직 Test Runner에서 돌려 보지 않음).

## 4. 일정 (안)

졸업작품 제출 시점에 맞춰 조정한다. 1주 = 한 단계 기준의 초안이다.

| 주차 | 단계 | 마일스톤 |
|---|---|---|
| 1 | 1, 2 | 로직 완성 (화면 없음) |
| 2~3 | 3, 4 | 플레이 가능한 첫 빌드 |
| 4 | 5 | **M1: 웹 프로토타입 동등** — 중간 발표 가능 |
| 5~6 | 6 | **M2: 불가능 문제 자동 생성** — 이 게임의 핵심 차별점 |
| 7 | 7 | 점수 체계 |
| 8~9 | 8 | 다듬기, 사용자 테스트 |
| 10 | 9 | **M3: 제출** |

## 5. 결정이 필요한 항목

명세서 10장에서 넘어온 것. 해당 단계에 들어가기 전까지 정하면 된다.

| 항목 | 필요한 시점 | 현재 가정 |
|---|---|---|
| 생성 모드의 불가능 문제 비율 | 6단계 | **결정: 10~20% 무작위** |
| 시간 가산점 공식 | 7단계 | **결정: 쉬움 1분·보통 3분·어려움 6분 안에 정답이면 +1** |
| 정식 모드에서 "내 모형 평면도 표시" 허용 여부 | 7단계 | **결정: 연습(샘플) 모드에서만 허용, 켠 문제는 점수 미반영** |
| 졸업작품 제출일과 필수 제출물 | 지금 | 10주 일정으로 가정 |

## 6. 위험 요소

| 위험 | 대응 |
|---|---|
| 솔버가 5×5×3에서 느릴 수 있음 | 실루엣·색 가림으로 먼저 가지치기, 시간 제한을 두고 초과하면 그 seed는 버림 |
| WebGL 빌드에서 한글 글꼴이 안 나옴 | 4단계에서 한글 글꼴(Noto Sans KR)을 프로젝트에 포함 |
| 웹판과 난수 결과가 미세하게 달라짐(부동소수점) | 1단계에서 웹판 결과를 테스트에 고정해 바로 발견 |
