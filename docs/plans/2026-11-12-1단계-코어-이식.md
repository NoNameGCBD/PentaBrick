> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 웹 프로토타입의 core(모형·평면도·판정·샘플 문제·생성기)를 Unity 프로젝트 안의 순수 C# 어셈블리로 옮기고, 같은 테스트를 통과시킨다.

**Architecture:** `unity/Assets/PentaBrick/Core`는 UnityEngine을 참조하지 않는 어셈블리(`noEngineReferences`)다. 테스트는 NUnit으로 쓰고 Unity Test Runner(EditMode)와 `dotnet test` 양쪽에서 같은 소스로 돌린다.

**Tech Stack:** Unity 6000.6.1f1 (URP 템플릿), C# 9, NUnit 3, .NET SDK 10(명령줄 테스트용)

**Spec:** [docs/기획명세서.md](../기획명세서.md) 2장, 4장, 6장. 원본 코드 `src/core/*.js`, 원본 테스트 `tests/core.test.js`.

## Global Constraints

- 좌표계: x 왼쪽(0)→오른쪽, y 바닥(0)→위, z 뒤(0)→앞. `columns[z * size + x]` = 아래→위 색 번호.
- 색 번호: 1 빨강, 2 주황, 3 노랑, 4 초록, 5 파랑, 6 보라. 0은 빈칸.
- 모형은 불변. 편집 함수는 새 모형을 돌려주고, 실패하면 `null`.
- 점수: 제출 ±1, 불가능 선언 ±2.
- 난이도: 쉬움 3×3×3·3색·6~10개·60% / 보통 4×4×3·4색·12~20개·65% / 어려움 5×5×3·6색·22~36개·65%.
- 같은 난이도와 seed는 웹 프로토타입과 **같은 문제**를 만들어야 한다 (mulberry32, 호출 순서 동일).
- Core에는 `using UnityEngine` 금지. C# 9까지만 사용(`record`, `init` 금지 — Unity에서 컴파일되지 않음).
